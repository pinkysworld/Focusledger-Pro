# Focusledger Pro

GitHub Pages site for the Focusledger direct-download macOS editions.

- Live page: https://minh.systems/Focusledger-Pro/
- Focusledger Pro: https://michelpicker.gumroad.com/l/focusledger
- Focusledger Lite: https://michelpicker.gumroad.com/l/focusledger-lite

Focusledger Lite is free/pay-what-you-want for focus sessions, Pomodoro, goals, journal, notes, manual insights, and export.

Focusledger Pro is the paid direct-download build with automatic app tracking, window-title context, visual timelines, optional screenshots, detailed analytics, and comparison views.
